# Phase 4: KEMBANG — Scale Guidelines

**Weeks 13-16 | Theme:** Show proof. Systematize. Go/no-go decision.

---

## 1. The Go/No-Go Decision

### Criteria

| Metric | Threshold | Current | Pass? |
|--------|-----------|:-------:|:----:|
| Active subscribers | ≥ 5 | | ☐ |
| Demo-to-close rate | ≥ 30% | | ☐ |
| Monthly churn | < 10% | | ☐ |
| Build time per site | < 6 hours | | ☐ |
| Service-related churn | 0 clients lost to service issues | | ☐ |

### Decision

If 3 of 5 pass → **GO.** Continue scaling. Consider:

- Second niche (plumbing? electrical? renovation?)
- Increase outreach volume (15-20/week)
- Standardise pricing
- Start content repurposing pipeline for YouTube + Instagram

If 3 of 5 miss → **PIVOT.** Options:

| Problem | Pivot |
|---------|-------|
| Build time too long | Template system, component library, or different tool |
| Close rate too low | Revise outreach scripts, demo quality, or pricing |
| Churn too high | Interview churned clients. Fix what they say. |
| Not enough leads | Increase FB group presence. Try different groups. |
| Wrong niche | Different trade? Different area? Different pricing? |

## 7. Phase 4 Content Focus

### Content Pillar Shift

| Phase 1-2 | Phase 3-4 |
|-----------|-----------|
| "This is the problem" | "Here's how we solved it" |
| General data | Specific results |
| Observation | Testimonial |
| "What I found" | "What happened next" |

### Key Content for Phase 4

- "3 months in — subscribers, leads, lessons learned" (retrospective)
- "Contractor X got Y leads in first month" (client result)
- "What I'd do differently if I started over" (vulnerable + helpful)
- "The exact outreach script that closed our first 3 clients" (transparency)
- YouTube: Month 3 retrospective (5-min screen recording)

## Touch 1 — First Outreach (Day 0)

### Standard (no online presence)
```
Hi [Name], saya sempat check — every bulan roughly 290 orang
search aircond service kat area [Area]. Tapi [Business Name]
tak nampak langsung dalam result.
Saya dah sediakan report + demo untuk tunjuk macam mana
customer boleh jumpa awak: [report URL]

Ada apa-apa boleh tanya sini.
```

### Social-aware (Instagram/TikTok active)
```
Hi [Name], nampak [Business Name] ada IG aktif — project photos
bagus. Tapi masa saya check, customer yang search Google
kat area [Area] tak nampak bisnes awak langsung.
Saya ada report pasal customer yang missed tu:
[report URL]

Boleh tengok bila free.
```

### Has weak website
```
Hi [Name], saya check website [Business Name] — nampak
dah ada tapak. Tapi customer still susah nak jumpa.
Saya dah sediakan report + cara boleh improve supaya
lebih ramai customer dapat cari awak: [report URL]
```

### Rules for Touch 1
- Lead with **customer/revenue**, not website/tech
- Under 4 lines total
- Report link in every first message
- No price mention
- No "pakej" or "promosi" language
- End with soft open — never a question that demands commitment
- Use their actual business name

## Touch 2 — Follow Up (Day 3)

Only send if no reply. Always attach a new observation.

### Customer angle
```
Just nak check — awak dah tengok report tu? 290 orang
search aircond service [area] sebulan. Bayangkan kalau
5% dari tu jadi customer awak — 15 customer baru sebulan.
```

### Report check
```
Link report tu okay ke dari phone? Nak saya hantar
screenshot ringkas?
```

### Why this works
Reframes from "did you see my website" to "did you see how many customers you're missing." The latter is harder to ignore.

## Touch 3 — Soft Close (Day 7)

No reply. Mild scarcity — but framed around customer opportunity, not website slots.

```
Report untuk [Business Name] still ada. Setiap hari
lambat, maybe 5-10 customer lagi call competitor
instead of awak.

Saya akan mula fokus area lain hujung minggu ni.
Kalau rasa relevant, reach out sini before tu.
Kalau tak, okay je. Takde hard feelings.
```

### What this does
- "Customer call competitor instead" creates urgency
- "Fokus area lain" implies competitor gets the opportunity
- "Okay je" removes pressure — paradoxically increases replies
- This is your last touch before moving on

## Handling Replies

### "Berapa harga?"
Never answer with a number immediately. Build value first. Then present pricing clearly.

```
Bergantung pada apa yang awak nak. Tapi sebelum tu —
awak dah tengok demo tu? Baru senang cerita.

Dua pilihan:

1. RM 297 — fi setup. Saya bina website.
2. RM 149 — activation + bulan pertama. Balance RM149
   untuk activate + bulan pertama. Renewal RM149/bulan
   bermula bulan ke-3.

Satu job chemical wash RM 150-300 dah cover sebulan.
Awak dah tengok demo ke belum?
```

Get them to confirm they've seen the demo before discussing price.
Price after value, never before.

### "Boleh fikir dulu"
Acknowledge and stay warm. No push.

```
Okay no problem. Report still up kat link tu —
bila-bila rasa nak proceed, reach out sini.

Sementara tu, cuba Google "[service] [area]" —
tengok apa competitor awak nampak. Menarik.
```

The "cuba Google sendiri" hook keeps them thinking.

### "Macam mana nak proceed?"
Green light. Move fast.

```
Senang je. Dua pilihan:

1. RM 297 — fi setup. Saya bina website.
2. RM 149 — activation + bulan pertama. Renewal RM149/bulan
   bermula bulan ke-3. Tiada kontrak.

Payment ke Maybank: 562021737846 (PintarWeb Enterprise)

Selepas payment, saya WhatsApp awak untuk collect:
→ Logo bisnes (file atau link FB page)
→ Gambar kerja sebenar
→ Maklumat servis dan kawasan

Website live dalam 4 minggu.
```

Notice: Price mentioned only **after** they've initiated.

### "Tak berminat"
Never argue. Pivot to referral.

```
Faham, terima kasih sebab reply! Kalau ada kawan
contractor aircond atau renov yang nak dapat lebih
customer — boleh refer saya. Dapat 1 bulan free
kalau jadi subscriber.
```

### No reply after Touch 3
Move on. Mark as closed-lost. Revisit in 3 months.

## Closing Sequence

When a lead is warm and engaging:

**Step 1 — Confirm they've seen the customer data**
"Dah sempat tengok report pasal customer yang missed tu?"

**Step 2 — Invite feedback**
"Dari report tu, ada apa-apa yang nak discuss?"

**Step 3 — Make a small tweak**
Do one thing they suggest within the same day. Proves responsiveness.

**Step 4 — Connect to their business**
```
Dengan sistem ni, orang search "[service] [area]" —
diorang nampak bisnes awak. Call awak. Bayar awak.

Bila awak atas bumbung fix compressor, auto-reply
WhatsApp tangkap lead — customer baru punya inquiry
tak miss. Kita handle semua — awak fokus buat kerja.
```

**Step 5 — State price clearly**
```
Dua pilihan:

1. RM 297 — fi setup. Saya bina website.
2. RM 149 — activation + bulan pertama. Renewal RM149/bulan
   bermula bulan ke-3. Tiada kontrak.

Satu job RM 150-300 dah cover sebulan.
```

**Step 6 — Remove payment friction**
- Accept DuitNow, bank transfer, Billplz, cash
- 3-month advance (RM 447) upfront, then auto-renew monthly
- Send DuitNow QR / payment link immediately when they agree
- Don't invoice — just confirm receipt via WhatsApp
- Note: auto-renew billing will be set up via Billplz for recurring payments

## Output 1: Screenshot Script

**File:** `scripts/generate-screenshot.sh`

**What it does:**
- Accepts `--url` and `--output` arguments
- Launches Playwright (from `../pintarweb-scraper/node_modules/playwright`)
- Opens `--url` in headless Chromium
- Captures screenshot at 390px width (mobile-first)
- Saves to `--output` path as PNG
- Closes browser

**Usage:**
```bash
bash scripts/generate-screenshot.sh \
  --url "https://preview.pintarweb.com/{id}/" \
  --output "data/screenshots/{id}.png"
```

**Output:** PNG file at `data/screenshots/{id}.png`

**Integration:** Called at end of `generate-demo.sh`, prints output path. Screenshot attached manually to WhatsApp.

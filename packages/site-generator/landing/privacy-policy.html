Privasi dan Perlindungan Data Peribadi

Kemas kini terakhir: 23 Jun 2026

Ringkasan: Pintarweb komited untuk melindungi data peribadi anda. Kami hanya mengumpul data yang diperlukan untuk menyediakan perkhidmatan, tidak menjual data kepada pihak ketiga, dan anda boleh meminta akses, pembetulan, atau pemadaman data anda pada bila-bila masa.

1. Pengenalan

Pintarweb ("kami", "kita", "our") menghormati privasi anda dan komited untuk melindungi data peribadi anda. Dasar privasi ini menerangkan bagaimana kami mengumpul, menggunakan, dan melindungi data anda apabila anda menggunakan perkhidmatan kami.

Dasar privasi ini mematuhi Akta Perlindungan Data Peribadi 2010 (PDPA) Malaysia.

2. Data Yang Kami Kumpul

2.1 Maklumat Perniagaan

Kami mengumpul maklumat berikut tentang perniagaan anda:

  • Nama perniagaan
  • Alamat perniagaan
  • Nombor telefon dan WhatsApp
  • Alamat emel
  • Google Business Profile URL
  • Akaun media sosial (Instagram, TikTok)
  • Logo dan foto projek

2.2 Data Laman Web

Apabila anda atau pelawat anda menggunakan laman web yang kami bina, kami mungkin mengumpul:

  • Alamat IP
  • Jenis pelayar (browser type)
  • Halaman yang dilawati
  • Masa dan tarikh lawatan
  • Rujukan laman web (referrer)

2.3 Data Pembayaran

Kami tidak menyimpan butiran kad kredit atau maklumat perbankan anda. Semua pembayaran diproses melalui Razorpay, penyedia pembayaran yang mematuhi PCI DSS.

  • Razorpay memproses pembayaran anda dengan selamat
  • Kami hanya menerima notifikasi bahawa pembayaran telah berjaya
  • Kami tidak melihat atau menyimpan nombor kad anda

3. Bagaimana Kami Menggunakan Data Anda

Kami menggunakan data anda untuk tujuan berikut:

3.1 Menyediakan Perkhidmatan

  • Membina dan menyelenggara laman web anda
  • Mengoptimumkan SEO untuk meningkatkan carian
  • Menyediakan WhatsApp auto-reply bot
  • Menguruskan Google Business Profile anda

3.2 Komunikasi

  • Menghantar notifikasi tentang langganan anda
  • Menghantar laporan prestasi bulanan
  • Merespon permintaan sokongan anda
  • Menghantar maklumat tentang kemas kini perkhidmatan

3.3 Penambahbaikan

  • Menganalisis penggunaan laman web untuk penambahbaikan
  • Menyelidik trend dan keperluan pelanggan
  • Membangunkan ciri dan perkhidmatan baru

3.4 Pematuhan Undang-undang

  • Mematuhi keperluan undang-undang Malaysia
  • Menyelesaikan pertikaian atau enforcing terma perkhidmatan

4. Perkongsian Data

Kami tidak menjual data anda kepada pihak ketiga. Kami berkongsi data hanya dengan penyedia perkhidmatan yang diperlukan untuk operasi kami:

4.1 Razorpay (Pemprosesan Pembayaran)

  • Data dikongsi: Nama, emel, nombor telefon, jumlah pembayaran
  • Tujuan: Memproses pembayaran anda
  • Privasi mereka: https://razorpay.com/privacy/

4.2 Cloudflare (Hosting dan Analitik)

  • Data dikongsi: Alamat IP, data lawatan laman web
  • Tujuan: Hosting laman web dan analitik prestasi
  • Privasi mereka: https://www.cloudflare.com/privacypolicy/

4.3 Google (Google Business Profile)

  • Data dikongsi: Maklumat perniagaan, lokasi, waktu operasi
  • Tujuan: Menguruskan Google Business Profile anda
  • Privasi mereka: https://policies.google.com/privacy
  • Nota: Hanya dikongsi dengan kebenaran anda

4.4 Umami (Analitik Laman Web)

  • Data dikongsi: Data lawatan tanpa pengenalan peribadi (anonymous)
  • Tujuan: Menganalisis prestasi laman web
  • Privasi mereka: https://umami.is/docs/collect-data

5. Penyimpanan Data

Kami menyimpan data anda untuk tempoh berikut:

Jenis Data Tempoh Penyimpanan
Maklumat perniagaan Tempoh langganan + 12 bulan
Data pembayaran 7 tahun (keperluan cukai)
Data analitik 24 bulan
Log sokongan 12 bulan selepas langganan tamat

6. Keselamatan Data

Kami mengambil langkah-langkah berikut untuk melindungi data anda:

  • Enkripsi: Semua data dihantar melalui HTTPS/TLS
  • Akses terhad: Hanya Yus (pemilik Pintarweb) mempunyai akses kepada data pelanggan
  • Backup: Data di-backup secara berkala untuk mencegah kehilangan
  • Tiada perkongsian awam: Data pelanggan tidak dipaparkan secara awam

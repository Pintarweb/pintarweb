# Demo Site Quality Checklist

## Mobile check (390px width)
- [ ] Hero loads correctly and text is readable
- [ ] WhatsApp CTA button is visible without scrolling
- [ ] Phone number is visible in the first screen
- [ ] No horizontal scroll
- [ ] Navigation is functional and not broken
- [ ] Images load and are not stretched or cropped badly
- [ ] Font sizes are readable (no text under 14px)
- [ ] Buttons are large enough to tap (min 44px height)

## Content check
- [ ] Business name is correct and matches their Google listing
- [ ] Phone number is correct and clickable (tel: link)
- [ ] Language toggle button for english and BM is translating all the contents
- [ ] WhatsApp number links correctly (wa.me/ format)
- [ ] Service area is mentioned and accurate
- [ ] Services listed match what the business actually offers
- [ ] No placeholder text ("Lorem ipsum", "Business Name Here", "[INSERT]")
- [ ] No generic stock photos of Western business settings
- [ ] Testimonials sound like real Malaysian people, not corporate reviews
- [ ] No forbidden copy words (check copy-rules.md)

## Design check
- [ ] Max 2 fonts used
- [ ] Color palette is consistent throughout
- [ ] No broken layouts or misaligned sections
- [ ] Spacing feels balanced — not too cramped, not too empty
- [ ] No SaaS/startup aesthetic elements
- [ ] Trust signals visible above the fold
- [ ] Site looks like it belongs to THIS specific business, not a template

## Technical check
- [ ] Page loads in under 3 seconds on mobile (test with slow 4G in DevTools)
- [ ] All links work (phone, WhatsApp, any nav links)
- [ ] No console errors on load
- [ ] Preview URL is accessible (not behind auth)
- [ ] URL is clean and shareable

## Believability check (most important)
- [ ] Would a real SME owner look at this and think "this could be my business"?
- [ ] Does it feel locally grounded, not globally generic?
- [ ] Would you be comfortable sending this to someone you know?

If any box is unchecked — fix it before sending.
